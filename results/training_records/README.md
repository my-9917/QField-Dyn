# 训练设置

主模型采用三轮训练，每轮2,048个体系、6,144个CFM前缀和1,536次参数更新；稀疏rollout监督每轮覆盖128个轮换体系、384个前缀。学习率依次为1e-4、1e-4和3e-5。训练按预设三轮日程结束，收敛状态为`converged=false`。损失、验证损失和耗时见`training_summary.csv`，详细优化统计见`training_history.json`。

主模型的前序CFM训练包含9,846个体系；结构适配阶段包含128个训练体系。验证名单排除本模型各阶段及NeuralMD作者训练集中的复合物ID。

结构适配器在冻结主模型上训练4轮，共384次更新，包含64,262个可训练参数。本次评价采用主模型第三轮及适配器第二轮权重，权重文件和SHA256身份见仓库根目录`models/`与`results/truth90/manifest.json`。结构与损失参数见`adapter_config.json`。
